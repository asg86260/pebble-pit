Deep number glyphs: k, m, b and a point

Fight numbers over the endless serpent reach +181432 (level 25) and +1965763 (level 50). They need suffixes.

This is a mock. It is drawn from plain canvas shapes, not the game. Digits are copied exactly from NUM_FONT (src/config/deepdraw.js). It cannot show: the real camera and coil, the number flying into the bar's fill, the speed lines of a big blow, the dark-page negative, or how a wider string sits against the coil at the screen edge. The strips below imitate the kick arc and the heal's climb and swell with the game's constants, nothing more.

1. The font today

Four font pixels by six, one font pixel between glyphs, a drop line one font pixel under, two screen pixels a font pixel (a big blow gets three). Only 0-9 and + exist.

2. Suffix and point glyphs, three options

Each shown at 1x and 4x with the real drop line. Widths vary where the letter needs it (m is 5 wide); the glyph sheet would need a width per glyph, a small change.

3. Shortening rule

The yard already has one: fmt in src/words.js (see section 6). The three rules:

  • Yard: the HUD's fmt as is. One decimal below 99.95 of a unit, whole above (18.4k, 181k, 2m, 21.6m).
  • 3 figures: always three significant figures (1.23k, 18.4k, 181k, 1.97m, 21.6m).
  • Whole: no point at all (1k, 18k, 181k, 2m, 22m). Drops the "." glyph entirely.

Under 1000 every rule prints the number whole. Rounding up to 1000 of a unit rolls to the next suffix (999999 is 1m).

5. Reading it

  • A, lowercase: familiar and the widest read; m is the widest glyph and sits low.
  • B, capitals: same height as digits so a suffix never looks like a different kind of mark; K and M are crowded at four wide.
  • C, raised: the suffix is small and top-aligned like an exponent; keeps the string short, but at 2px a font pixel the m is only 5x4 cells.

6. What the yard does

export const fmt = n => {
  const v = Math.round(n || 0), a = Math.abs(v);
  if (a < 1000) return String(v);
  for (const [d, s] of [[1e9,'b'],[1e6,'m'],[1e3,'k']]) {
    if (a < d) continue;
    const q = Math.abs(v) / d;
    const t = q >= 99.95 ? Math.round(q) : Math.round(q * 10) / 10;
    if (t >= 1000) return (v<0?'-':'') + 1 + {k:'m',m:'b',b:'t'}[s];
    return (v<0?'-':'') + t + s;
  }
};

Lowercase k, m, b (and t on overflow), one decimal under 100 of a unit, whole above, trailing ".0" dropped by number-to-string. Matching it in the deep needs nothing new except the point glyph (and a t if ever needed: it is not reached at the serpent's numbers).
